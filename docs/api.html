Read features

GET /collections/buildings/items?sources=1&limit=10
Accept: application/geo+json

Use bbox=west,south,east,north in longitude/latitude (CRS84). Follow next links for additional pages and each feature's self link for individual access.

sources selects source IDs, intersected with X-Source-Ids if both are supplied. Omitting both returns no features. These are data filters, not authentication.

Static features match every valid RFC3339 datetime instant or interval. Unknown parameters return 400. Busy workers return 429 with Retry-After: 1.

Arrow Flight

Use ListFlights, GetSchema, and GetFlightInfo for discovery. Descriptors are a one-part collection path or a JSON command. DoGet accepts a UTF-8 JSON ticket:

{"collection":"buildings","sources":[1],"columns":["id","geometry","properties"],"limit":10000}

Geometry is WKB in CRS84; properties are JSON strings. Empty results include an Arrow schema.
